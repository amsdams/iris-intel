by searching class/id fragments from each selector across `apps/iitc-iris/src/**/*.ts`, `apps/iitc-iris/src/**/*.tsx`,
and adjacent JS/JSX source files. Fragment search is evidence for inventory triage, not final ownership proof.

Selectors with no source-tree fragment evidence are marked `UNCERTAIN` unless they target known external/IITC/Leaflet
DOM. No selector is classified as unused in this inventory.
