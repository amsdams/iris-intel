# IITC IRIS CSS Ownership Map - Phase 1

Status: Proposed ownership map for human review. This is the migration contract candidate, not approval to move CSS yet.

Source inventory: `01-css-inventory.md`.

## Method

This map uses the selector-complete Phase 1 inventory: 566 selector entries extracted from
`apps/iitc-iris/src/iitc-iris.css`. Each row maps the current selector to a proposed target CSS file based on existing
source directories, selector prefix, external DOM behavior, and TS/TSX fragment evidence.

Rules used for this proposed map:

- Shared primitives and component wrappers target `apps/iitc-iris/src/ui/`.
- Feature-prefixed selectors target their existing feature directory.
- Shell/sheet layout selectors target `apps/iitc-iris/src/shell/shell.css`.
- Global root/team/foundation selectors target `apps/iitc-iris/src/styles/`.
- Leaflet/player-tracker runtime selectors target `apps/iitc-iris/src/map/player-tracker.css`.
- Selectors without current source evidence are not deleted; they are marked `KEEP_TEMPORARILY` unless they are known
  runtime-generated selectors.

## Review Notes

- This map intentionally keeps class names and selectors unchanged.
- `KEEP_TEMPORARILY` means the selector may be migrated later, but only after a reviewer confirms ownership/cascade
  safety.
- `UNCERTAIN` means the selector has no reliable source evidence and should remain in `iitc-iris.css` until usage is
  proven.
- Proposed target files do not need to be created until Phase 2, and only after human approval.
